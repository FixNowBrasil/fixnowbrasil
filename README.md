# FixIt Now

Quero criar um aplicativo web responsivo chamado FIXNOW.

CONCEITO DO PRODUTO

O FixNow será um marketplace de serviços do dia a dia, inspirado na experiência de descoberta e contratação de serviços do iFood, mas voltado para serviços presenciais.

A proposta é conectar pessoas que precisam resolver problemas ou contratar serviços com profissionais e empresas que oferecem esses serviços.

Exemplos:

- Eletricista

- Encanador

- Técnico de ar-condicionado

- Instalação de ar-condicionado

- Montagem de móveis

- Instalação de móveis

- Pintor

- Pedreiro

- Técnico de informática

- Manutenção de eletrodomésticos

- Instalação de TV

- Instalação de suporte

- Chaveiro

- Limpeza

- Jardinagem

- Dedetização

- Pequenos reparos

- Marido de aluguel

- Instalação de tomadas

- Instalação de ventiladores

- Instalação de chuveiro

- Outros serviços residenciais e comerciais

O objetivo é tornar a contratação de serviços tão simples quanto pedir comida em um aplicativo.

NOME

FixNow

Slogan inicial:

"Precisou? FixNow."

POSICIONAMENTO

O FixNow não deve parecer um simples diretório de profissionais.

Ele deve parecer um marketplace moderno onde o usuário:

1. Encontra o serviço que precisa.

2. Informa o que precisa ser feito.

3. Encontra profissionais disponíveis.

4. Visualiza avaliações, experiência, distância e preço/faixa de preço.

5. Solicita orçamento ou contratação.

6. Agenda o serviço.

7. Acompanha o status.

8. Avalia o profissional após o serviço.

O produto deve transmitir:

- confiança

- praticidade

- rapidez

- segurança

- profissionalismo

- facilidade

==================================================

No topo:

"Olá! O que você precisa resolver hoje?"

Campo de pesquisa:

"Digite um serviço ou problema..."

Abaixo, mostrar categorias em cards/ícones.

Exemplo:

⚡ Elétrica

💧 Hidráulica

❄️ Ar-condicionado

🪑 Montagem

📺 Instalações

🧹 Limpeza

🌱 Jardinagem

FLUXO DE CONTRATAÇÃO

==================================================

O fluxo deve ser simples e semelhante à lógica de um marketplace.

Exemplo:

"Instalação de TV"

Depois o sistema pergunta:

"O que você precisa?"

Exemplo:

- Instalar TV na parede

- Instalar suporte

- Retirar TV antiga

- Outro

Depois:

"Conte um pouco mais sobre o serviço"

Campo de texto.

Permitir adicionar fotos do problema/local.

Depois:

"Quando você precisa?"

- Agora

- Hoje

- Amanhã

- Escolher data

Depois:

"Qual é o endereço?"

Utilizar localização/endereço do usuário.

Finalmente:

"Encontrar profissionais"

O sistema mostra prestadores compatíveis.
